# 調査レポート索引

技術調査・ライブラリ比較・選定の成果物は、本リポジトリには置かない。

## 保存先

- gitignore 済みの `.agent/.config` を読む
- `PRIVATE_REPO`: 非公開リポジトリ（`username/repo` 形式）
- `PRIVATE_DIR`: プロジェクトルートからの相対パス
- 調査レポート本体: `PRIVATE_DIR` 配下の `docs/research/`（`YYYY-MM-DD-slug.md` 形式）
- SF6 配置ビジュアライザ関連: 同リポの `docs/research/sf6-site/visualiza/`

## エージェント向け

調査を新規作成・更新するときは、`PRIVATE_DIR` 側に保存し、同リポの索引（`docs/research/index.md` または `docs/research/sf6-site/visualiza/README.md`）に追記する。本リポジトリの `docs/research/` には結論や比較内容を書かない。設定値そのものを文書・コメント・メモリへコピーしない。
